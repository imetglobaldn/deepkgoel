# Shared memory for Codex and Claude Code

Both Codex and Claude Code work on this site. This file records what changed while Claude Code took over from Codex (November 2026), the rules that came out of that work, and what is still open. Read it before changing the site, and add to it when you finish a piece of work so the other tool knows.

Last updated: 23 November 2026.

## Standing rules

- **No long dashes (U+2014) anywhere in the project.** Karan replaced them all with hyphens on 23 November 2026. Use a hyphen with spaces, a comma, a colon or a full stop instead.
- **Images: Codex first.** Generate with the Codex CLI (Karan's ChatGPT plan). Use the paid OpenAI image API only when Karan names it in that message. Reuse files in `C:\Users\Karan\.codex\generated_images\` before generating. Copy what you use into `public/images/`, never link to the Codex folder.
- **Record where every image came from** in `app/data/sources.json`. Say plainly when a picture is generated, so it is never mistaken for a real event.
- **Commit only when Karan asks**, directly on `main` (his choice). Never push unless asked.
- **Next.js 16.4.6 differs from older versions.** Read `node_modules/next/dist/docs/` before writing Next code (see `AGENTS.md`). Example: `<Image preload>` replaced `priority`.
- **Check changes visually.** Karan reviews at a 1520x776 window; also check a phone (390x844) and a large desktop (1920x969). Playwright is installed under `temp/v2-qa/node_modules`.
- **Respect reduced motion.** Every animation must switch off under `prefers-reduced-motion: reduce`.

## Where things live

- `app/globals.css`: the only stylesheet (`site-` class prefix). Motion timings at the top: `--ease-ios`, `--spring`, `--spring-bouncy`.
- `app/components/UI.tsx`: shared pieces (`Surface`, `PageIntro`, `IntroBackdrop`, `Portrait`, buttons, cards, footer).
- `app/components/Chrome.tsx`: header (hides on scroll down), scroll-reveal script (`data-reveal`), image drag blocking.
- `app/components/PageTransition.tsx`: wraps every page; drives page-to-page animation.
- `app/components/Disclosure.tsx`: the animated open/close lists; a shared `group` keeps one open.
- `app/components/PhotoCarousel.tsx`: the scroll-snap photo gallery with thumbnails.
- `app/data/`: all copy and content (`content.ts`, `about.ts`, `expertise.ts`, `contact.ts`, `media.ts`, `quotes.ts`, `articles.json`), site metadata (`site.ts`) and sources (`sources.json`).
- Full-size image originals exist only in `temp/` (gitignored), mainly `temp/default-theme-migration/previous/public/v9/` and the old WordPress copy in `temp/_deepakgoel.in/public_html/wp-content/uploads/`. Do not delete `temp/`.
